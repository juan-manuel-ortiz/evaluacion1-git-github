# Hackaton ADSO 2026

Sitio web para presentar la informacion principal de la Hackaton ADSO 2026.

## Descripcion

Este proyecto contiene la pagina web de la Hackaton ADSO 2026 desarrollada como evaluacion practica de Git y GitHub.

## Agenda

La pagina incluira actividades como:

- Apertura del evento
- Desarrollo de proyectos
- Presentacion de resultados

## Inscripcion

Los participantes podran consultar los requisitos, cupos disponibles y medios de contacto para realizar la inscripcion.

## Ubicacion

La pagina mostrara la direccion del evento y un enlace para consultar la ubicacion en un mapa.
