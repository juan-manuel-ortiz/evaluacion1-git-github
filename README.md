# Hackaton ADSO 2026

Sitio web con la informacion principal de la Hackaton ADSO 2026.

## Descripcion

Este proyecto presenta la informacion de la Hackaton ADSO 2026 y fue desarrollado como evaluacion practica de Git y GitHub.

## Agenda

La agenda del evento incluye:

- Apertura del evento
- Desarrollo de proyectos
- Presentacion de avances
- Presentacion de resultados

## Inscripcion

Los aprendices pueden consultar el cupo, los requisitos y el medio de contacto para realizar la inscripcion.

## Ubicacion

El evento se realizara en el CDITI SENA Dosquebradas y la pagina incluye un enlace para consultar el mapa.
